Architecture

A static app, one Cloudflare Worker, and one Solana program that runs inside MagicBlock's Private Ephemeral Rollup.

A gameweek onchain

Daily gameweeks: deadline 20:00 UTC, 24 hours long. Points use opening TWAP vs closing TWAP, never a single trade.

Sponsored actions (no SOL, no pop-ups)

Players start with an empty Solana account. The game Worker pays fees, but only for an allowlist of game instructions.

Why 5b: Solana's public devnet RPC blocks requests from Cloudflare Workers. Allowed instructions: create and delegate a profile or an entry (Solana), seal a squad or rename (TEE).

The price book and TWAP

One account on the Private ER. Every minute the Worker writes all prices; each write also adds price x seconds to a running sum per stock.
